# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Static HTML, CSS, and plain JavaScript, explicitly requested by the student.
No frameworks, backend, or required build step. JavaScript libraries are allowed
only when they provide a concrete benefit. None is needed for the proposed v1.

## Users

Two local players sharing one device. The student also needs to inspect the
source and demonstrate the development process to the laboratory evaluator.

## Product Purpose

Build a complete snakes and ladders game while preserving evidence of planning,
human review, implementation, and subsequent prompt refinement iterations.

## Operating Context

This exercise is independent of the other repository exercises. The interface
and laboratory evidence use Spanish. The deliverable must include the visible
conversation, plans, results, screenshots, and links to each Markdown document.
The assignment requires a PDF if the completed work is not demonstrated in class.

## Capabilities and Constraints

- First phase: a complete initial game, with later refinements kept as separate
  stages rather than presented as work already completed.
- Two local players, confirmed through the planning questionnaire.
- Visual effects in separate files, integrated directly into the game, confirmed
  through the planning questionnaire.
- Simple, readable game code; lightweight animation and a noticeable sense of volume.
- Plan before implementation. The student explicitly interprets "Build" in
  assignment instruction 3 as an error and chooses Plan instead.
- Later stages: a user-requested improvement using a reference image, then another
  iteration adding a choice among three scenarios.
- The user approved the written first-phase plan with "Hazlo implementalo".
  The resulting code and evidence still require the student's human review.

## Brand Commitments

The user selected "Diorama colorido": a toy-like board with relief, solid pieces,
a light background, and lively colors. No logo or additional brand was supplied.

## Evidence on Hand

- `AGENTS.md`: laboratory instructions and documentation requirements.
- `docs/evidence/00-assignment.png`: unchanged copy of the assignment image.
- `docs/conversations/00-planning.md`: available visible conversation and recorded
  questionnaire choices, with its completeness limitations stated explicitly.

## Product Principles

- Keep game rules independent of visual embellishments.
- Prefer native browser features and readable code over extra dependencies.
- Make turn, position, die result, and winner clear to both players.
- Preserve real evidence and never invent human approval or test results.

## Accessibility & Inclusion

Support keyboard use, visible focus, readable contrast, and small screens.
Respect reduced motion without changing the rules or preventing play. Distinguish
players with labels and piece markings as well as color.
