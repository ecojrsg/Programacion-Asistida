## Descripción

Aplicación que conserva tareas en el estado de sesión, permite agregar tareas no vacías y las muestra numeradas.

- [add_task.py](add_task.py)

## Ejecución

```text
python -m streamlit run app.py
```

## Salida en terminal

```text
Local URL: http://localhost:8501
You can now view your Streamlit app in your browser.
```

Resultado esperado en la interfaz: una tarea no vacía se conserva en la sesión y aparece numerada en la lista.
