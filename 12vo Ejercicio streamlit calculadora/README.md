## Descripción

Calculadora interactiva con suma, resta, multiplicación y división, incluyendo validación de división entre cero.

## Código

- [app.py](app.py)
- [PDF del ejercicio](../PDFs%20ejercicios/Ejercicio_12_Ejercicio_de_Streamlit_calculadora.pdf)

## Ejecución

```text
python -m streamlit run app.py
```

## Salida en terminal

```text
Local URL: http://localhost:8501
You can now view your Streamlit app in your browser.
```

Resultado esperado en la interfaz: al dividir entre cero muestra `No se puede dividir entre cero.`
